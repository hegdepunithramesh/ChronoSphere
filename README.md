Project Title
ChronoSphere: A Historical Timeline

Project Description
ChronoSphere is a web application that serves as a portal to history. Users can select any date and discover a timeline of significant events, notable births, and influential deaths that occurred on that day throughout history. The project is built with a modern, responsive design and a clean architecture, separating the frontend from the backend.

Features
Interactive Date Selection: A simple and intuitive date picker allows users to choose any day.

Dynamic Timeline Display: Fetches and displays historical data for the selected date.

Modular Architecture: Separates the frontend views (EJS) from the backend logic (Express.js).

External API Integration: Uses a third-party API to reliably retrieve historical data.

Responsive Design: The user interface is designed to work seamlessly on both desktop and mobile devices.

Technologies Used
Backend:

Node.js: The JavaScript runtime environment.

Express.js: A fast, unopinionated web framework for Node.js.

Axios: A promise-based HTTP client for making API requests.

Frontend:

EJS (Embedded JavaScript): A templating language to generate dynamic HTML.

HTML5 & CSS3: For structuring and styling the web pages.

Custom CSS: Hand-written styles for a unique and attractive user interface.

API:

Muffin Labs History API: The data source for all historical information.
